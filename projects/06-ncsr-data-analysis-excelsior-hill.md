# NCSR Data Analysis

| Field | Details |
|---|---|
| **Client** | Excelsior Hill University |
| **Date** | 2025 |
| **Type** | Cybersecurity Assessment / Data Analysis |
| **Framework** | NIST CSF v1.1 / NCSR |

---

## Overview

Compiled and analyzed NCSR control data for Excelsior Hill University in spreadsheet format. Provided a quantitative breakdown of maturity scores across all NIST CSF control families to serve as a data-driven companion to the cybersecurity audit report.

---

## Key Metrics

| Metric | Detail |
|---|---|
| Output Format | XLSX (Excel) |
| Control Families | 5 (Identify, Protect, Detect, Respond, Recover) |
| Score Range | 1–7 (NCSR Maturity Scale) |
| Framework | NIST CSF v1.1 / NCSR |

---

## Purpose & Outcome

- Served as the quantitative backbone for the Excelsior Hill audit report
- Enabled visual and comparative analysis of cybersecurity maturity across all five NIST CSF control functions
- Structured dataset supports leadership reporting, gap tracking, and trend analysis over time

---

## Frameworks Applied
- NIST Cybersecurity Framework (CSF) v1.1
- Nationwide Cybersecurity Review (NCSR)
