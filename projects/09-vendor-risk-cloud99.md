## Overview

Performed a structured annual vendor risk assessment on Cloud 99 Tech Solutions, a critical CRM provider with a $240,000/year contract. Evaluated risks across seven categories: operational, financial, security, compliance, reputational, strategic, and technology.

---

## Key Metrics

| Metric | Result |
|---|---|
| Contract Value | $240,000/year |
| Risk Categories Assessed | 7 |
| Overall Risk Rating | Medium |
| SLA Uptime (Target: 99.9%) | 99.95% — Exceeding target |
| Support Response Time (Target: < 2 hrs) | 1.5 hrs — Exceeding target |
| User Satisfaction (Target: 4.5/5) | 4.3/5 — Slightly below target |
| Security Incidents (Past Year) | 1 minor — Resolved within 24 hrs |

---

## Security Certifications

- SOC 2 Type II — Current
- ISO 27001 Certified
- Regular third-party penetration testing

---

## Key Concerns

| Concern | Detail |
|---|---|
| Security Team Turnover | 20% turnover rate — risk to institutional knowledge and control continuity |
| Legacy Code Components | Legacy components identified in core CRM system — potential vulnerability surface |
| User Satisfaction | 4.3/5 slightly below the 4.5 target — may signal emerging usability issues |

---

## Outcome

Approved for continued use with:
- Enhanced monitoring requirements
- Contingency plan to be developed within 90 days
- User satisfaction trend to be tracked at next quarterly review
